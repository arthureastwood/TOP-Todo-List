# TOP-Todo-List

Todo List Application developed using the single responsibility design principle to strip down 
file sizes and chain modules until the entry point, with webpack as 
the bundler to minify assets, html, css, js files and improve on the performance of any application.

This app includes features such as projects to organize tasks into groups, delete icons on todo cards and delete buttons inside the todo details modal of each todo task to make deletion 
of tasks effortless.

For the presentation layer, I used custom properties, gradients to make the colors of the application to make the interface look visually appealing.
